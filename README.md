# Episode-Studio

Episode Studio is an Obsidian plugin for writing and organizing episodic stories directly in your vault. It provides a panel-based script editor to keep scene descriptions, character text, and sound effects together while drafting each episode.

## Features

- Create and edit up to 200 numbered episodes.
- Save episodes as Markdown files (`Ep. 1.md` through `Ep. 200.md`) in a vault folder of your choice.
- Preview scripts in a clean reading mode.
- Add scene descriptions to panels.
- Add character Dialogue, Thought, and Monologue text.
- Add sound effects (SFX) to panels.
- Automatically save edits to episode Markdown files.
- Rename and renumber episode files when episodes are deleted.
